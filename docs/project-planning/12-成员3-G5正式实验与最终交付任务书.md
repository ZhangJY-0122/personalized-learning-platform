## 3. G5-02 统一清洗与防泄漏切分

实现可复现清洗脚本，输出：

- 统一交互 schema：外部用户、题目、技能、时间/序号、答案、正确性、来源版本。
- `external_id_map`，不得把公开数据 ID 直接当线上 UUID。
- 原始行数、保留行数、过滤原因和样本损失统计。
- 每名合格学生按顺序 70%/10%/20% 划分的 train/validation/test 清单。
- 固定随机种子、切分版本和输入 hash。

主实验评估的是“已见学生的未来作答预测”，不采用学生互斥切分。固定协议如下：

- 先按 `user_id` 分组，再按 `(order_id, problem_id, 原始行号)` 稳定排序。
- 每名学生先切分，再构造窗口；不得先滑窗后随机分割。
- 序列长度至少 5 才进入主比较，以保证 train/validation/test 至少分别有 3/1/1 条；更短序列只进入覆盖率统计，不静默丢弃。
- 训练段为前 70%，验证段为随后 10%，测试段为最后 20%；取整算法写入代码和 split manifest，保证三个分区互不重叠且并集等于该生完整序列。
- 目标交互只能属于一个分区。验证/测试可以使用该目标之前已揭示的历史作为上下文，但当前目标答案不能进入输入，模型参数不能在验证/测试阶段更新。
- item/skill vocabulary、标准化器、流行度、相似度矩阵和所有可学习统计只在训练段拟合；验证/测试未知项映射为 `<UNK>` 并单列覆盖率。
- 固定正式随机种子为 `11/22/33`；确定性 Rule/BKT 相同结果的标准差为 0 属正常。
- 可额外做“学生互斥的新学生泛化”敏感性分析，但必须单独命名，不能替代主协议，也不能与主结果混表。

输出 `artifacts/g5-cleaning-report.json`、`artifacts/g5-split-report.json` 和不可逆的 `data/manifests/g5-split-manifest.json`。这些产物记录输入 hash、脚本版本、过滤原因、取整规则和每个分区的行数/hash；不得提交原始用户 ID 列表。

## 5. G5-04 Rule/BKT/DKT 对比

对 Rule、BKT、DKT 使用同一数据切分和同一预测目标，至少输出 AUC、Accuracy、RMSE、LogLoss。每个实验记录：

- 数据版本、切分 hash、模型版本和随机种子。
- 训练轮数、超参数、硬件、耗时和失败运行。
- 每个 seed 的原始指标、均值和标准差。
- 模型文件、加载校验和与复现实验命令。

主比较统一使用“揭示当前答案前的下一次作答正确概率”。Accuracy 阈值固定 0.5，LogLoss 概率截断到 `[1e-6,1-1e-6]`；AUC 在目标只有单一类别时为 `null` 并解释。三种方法必须使用相同有效目标集合，另报告未知技能率和被排除样本数。

正式 DKT 预算：单层 LSTM、窗口 100、batch 32、最多 20 epoch、验证 LogLoss patience=3；调参最多 4 个配置（hidden size `32/64` × learning rate `0.001/0.0003`），只用 seed=11 和验证集选择一次。选定配置后用 `11/22/33` 三个 seed 重新训练；每个 seed 的测试集只评估一次。技术失败允许重跑一次，但失败运行和原因必须保留。默认 CPU 可完成，不把 GPU 作为复现前提；原始数据、派生数据、日志和 checkpoint 总磁盘预算不超过 5 GiB，超出前停线报告。

DKT 只能输出下一次作答正确概率，不得写回 BKT mastery；在线路径和薄弱点仍使用 BKT。DKT 不领先时保留真实结果并分析原因，不调换指标或伪造提升。输出 `artifacts/g5-kt-comparison.json`、每 seed checkpoint/checksum 和一条从清洗到评估的复现命令。

## 6. G5-05 五种推荐基线与消融

五种策略必须与上位方案一致，不得临时改名或把同一策略拆成两种：

1. `POPULAR`：训练段交互流行度。
2. `CONTENT`：训练段可见的题目—复合技能向量相似度。
3. `ITEM_CF`：训练段学生—题目二元交互矩阵的 Item-CF。
4. `HYBRID_NO_KT`：流行度、内容和 Item-CF 的验证集定权组合，不使用 KT。
5. `HYBRID_KT`：在上一策略基础上加入训练完成后冻结的 BKT 薄弱匹配。

候选集、过滤、顺序切点、冷启动和回退规则必须先冻结。权重只在验证集确定；测试排序不得读取未来行为。统一报告 Precision@5、Recall@5、HitRate@5、NDCG@5、Coverage、Diversity、有效用户数、无相关项用户数、短列表比例、未知题目率和回退比例，并完成去 KT、去 CF、去内容的消融。

ASSISTments 只有题目作答日志，没有可信资源浏览/完成记录。因此公开数据推荐实验只评估**题目推荐**；不得从题目作答虚构资源点击或把三门合成课程的资源结果包装成公开数据结果。资源+题目混合推荐只能作为 `SYNTHETIC_DEMO` 产品链路验收，必须与公开数据指标分表。

离线评价与产品线上推荐分开；实验结果必须来自机器生成 JSON/CSV，不使用 UI 点击或手工填表伪造结果。每个推荐结果绑定数据版本、目录版本、strategyVersion 和随机种子。
