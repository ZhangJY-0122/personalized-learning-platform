# 成员3 · G3 推荐与反馈实施及验收记录

更新日期：2026-09-12。状态：G3 推荐与反馈闭环已通过隔离验收；下一关卡为 G4 路径与恢复。

## 1. 交付范围

G3 在既有 G1 目录和 G2 可信作答链路上，交付电脑端的可解释推荐闭环：

- 固定资源和先修关系快照；推荐批次绑定目录版本、学习状态版本、目录签名和策略版本，30 分钟后失效。
- 推荐排序使用真实的同课程授权快照、BKT、证据、近期作答和可信资源偏好；客户端不能传入掌握度或偏好冒充可信来源。
- `GET /recommendations` 只读；`POST /generate` 使用幂等键生成并持久化批次。同键异请求冲突，学习状态正在处理或待重建时拒绝生成。
- 输出四分量评分、有效权重、数据来源和至少两条事实解释；候选经过课程、上架、关联、先修、近期题目与资源冷却等硬过滤。
- 记录曝光、点击、显式反馈、资源浏览和资源完成。自报完成不更新 BKT；资源行为只更新资源进度和偏好。
- 推荐题作答和推荐资源完成由服务端校验归因后派生唯一可信完成反馈；重复消费和重建不会重复派生。
- 网页提供推荐生成/刷新、评分明细、失效原因、资源打开与完成、推荐题作答、反馈和网络结果不明时的同键重试。

不包含学习路径、跨版本目录迁移、完整导入、正式公开数据实验或移动端。

## 2. 实现组成

V5 迁移新增资源与先修快照、推荐批次及明细、反馈/请求幂等、资源行为台账，并在作答表上增加推荐归因字段。实现位于：

- `f21-personalized-learning/server/src/main/java/edu/f21/recommendation/`：排序器、服务和 API 控制器。
- `f21-personalized-learning/server/src/main/resources/db/migration/V5__Recommendations_and_resource_activity.sql`：G3 增量表结构。
- `f21-personalized-learning/web/src/recommendations.js`：前端幂等请求、曝光/点击、资源行为与反馈。
- `f21-personalized-learning/web/src/main.js`：推荐页面及推荐题/资源入口。
- `f21-personalized-learning/tests/g3_acceptance.py`、`tests/g3-ui.cjs`：隔离 API、故障和浏览器验收。

排序规则保持一内容一知识点的演示边界。薄弱点需要至少 3 次有效证据、权重至少 2 且 BKT 小于 0.6；无证据时返回待诊断内容，全部达标时回退为巩固推荐。它不是已训练的题目级预测或最终多技能算法。

## 3. 验收结果

最新隔离验收产物为 `f21-personalized-learning/artifacts/g3-acceptance.json`：2026-09-12 通过，共 138 项 HTTP 检查，Flyway V5 成功应用，浏览器闭环通过。覆盖内容包括：

| 验收项 | 结果 |
| --- | --- |
| 权限与只读查询 | 学生本人访问、越权拒绝；空批次与处理中状态准确，GET 不创建状态 |
| 幂等与并发 | 并发生成、反馈、资源行为同键只写入一次；同键异内容冲突 |
| 推荐正确性 | 诊断模式返回资源与题目，评分明细可复算，旧批次读取不重算 |
| 可信归因 | 自报完成不改变 BKT；推荐资源完成与推荐题成功消费才派生可信反馈 |
| 失效处理 | 状态变更、30 分钟过期、目录内容不可用均标记旧结果和不可用项 |
| 事务与重建 | 可信完成失败回滚；重建不重复反馈；状态代次回滚正确 |
| 重启一致性 | 服务重启后批次、幂等结果和学习状态保持一致 |
| 电脑浏览器 | 1440×1000 下生成、同键重试、反馈、资源浏览/完成、推荐题归因与失效提示通过，无页面错误和第三方请求 |

排序器单测覆盖固定随机种子数值检查、先修图、候选过滤、冷启动、回退与非法输入；原 G1/G2 回归也在 G3 隔离环境中执行。验收在独立 Compose 项目和独立卷中运行，不向主开发库填充测试学习行为。

## 4. 已知边界与下一阶段

- 仅适用于本地单实例演示；生产级密码管理、HTTPS、限流、安全审计、备份恢复、依赖漏洞检查和性能压测未完成。
- 目录版本化目前覆盖 G2/G3 所需快照；完整导入、跨目录映射与补偿任务仍待实现。
- 路径 DAG、重规划、复测终止和路径故障注入属于 G4。
- 公开数据全量清洗、BKT 拟合、正式 DKT 与基线实验、三门课程和教师统计属于 G5/G6。

G3 通过不代表完整 F21 或团队 F13 综合平台完成；其定位是已冻结的推荐与反馈阶段交付。
