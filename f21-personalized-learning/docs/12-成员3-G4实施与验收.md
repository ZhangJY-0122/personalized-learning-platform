## 当前可复现实验

在 `f21-personalized-learning` 目录运行：

```bash
.venv/bin/python scripts/validate_contract.py
.venv/bin/python -m unittest discover -s tests -v
python3 tests/g4_acceptance.py
node tests/g4-ui.cjs
git diff --check
```

三项均应通过。纯路径算法的 Java 单测位于 `server/src/test/java/edu/f21/learningpath/LearningPathPlannerTest.java`，需在具备 JDK 17 与 Maven 的环境中执行。

## 环境限制与未宣称项

当前执行机没有可用的 JDK 运行时/Maven，也没有可运行的 MySQL/Compose 服务，因此没有伪造 Java 编译、Flyway 空库迁移、跨版本重建和浏览器截图结果。`npm run build` 需要先安装 web 目录依赖（当前环境缺少 `vite`）。

事件 JSON 导入已实现安全入队、幂等、重复/冲突分类和未知版本的 `PENDING_COMPENSATION` 状态；目录 JSON 原子导入、CSV 适配、跨目录 BKT 映射重建及完整管理员 UI 仍应由 Luna 在具备 JDK/MySQL/Node 依赖的环境按任务书 G4-07～G4-10 继续完成，不能把本记录当作全量 G4 通过证明。
